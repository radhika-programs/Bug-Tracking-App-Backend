Bug Tracking API
Project Overview

Bug Tracking API is a backend application designed to manage and track software bugs efficiently. It helps users create, update, retrieve, and manage bug reports through RESTful APIs.

Technologies Used

Spring Boot

Getting Started

Prerequisites

Java JDK
Maven
IDE such as Eclipse or IntelliJ IDEA
Run the application

Clone the repository:


bash
git clone https://github.com/radhika-programs/Bug-Tracking-api.git
Navigate into the project:


bash
cd Bug-Tracking-api
Run using Maven:


bash
./mvnw spring-boot:run
